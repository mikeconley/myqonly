0.12.0

New features

  • You can now ignore specific GitHub teams using the "Ignored teams" field. This filters out pull requests where only a team you're on has been requested for review. Thanks to Daniel Thorn (:relud) for this fix!
  • If you have GitHub repositories in the old format (e.g., "mozilla" instead of "mozilla/gecko-dev"), MyQOnly will now show a warning in the popup panel and offer a migration helper tool to convert them to the new format automatically.
  • The options page now validates GitHub repository format in real-time, showing an error if you enter repositories that aren't in the owner/repo format.

Changes

  • BREAKING: GitHub ignored repositories now require exact owner/repo format (e.g., mozilla/gecko-dev) instead of substring matching. This ensures the count in the badge matches what you see on GitHub. If you have old-format repositories configured, you'll see a migration warning with a helper tool to update them automatically.
  • MyQOnly now uses Manifest V3 and requires Firefox 109 or later. This modernizes the extension architecture for better performance and future compatibility.

Bug fixes

  • Fixed an issue where the GitHub review count could be incorrect when using ignored repositories. The count now properly reflects what the GitHub API returns after filtering. Thanks to Andrew Halberstadt (:ahal) for the patch!

  • Poor support for Containers
